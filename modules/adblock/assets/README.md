# adblock

Stream Spotify music without interruptions — block ads and unlock premium-like playback controls.

> [!NOTE]
> Enabled features include:
> - No forced shuffle
> - No forced repeat
> - Modifiable queue
> - No ads between songs and in the UI
> - No upsell popups about premium or popup ads

> [!CAUTION]
> This module **will not**:
> - Unlock native lyrics page
> - Let you download songs
> - Allow changing song quality to `Very High`
> - Allow listening with friends in Jams

## Install

Install via the Spicetify Marketplace module, or build from source:

```sh
cd modules && deno task pw:build && deno task pw:enable
```
